# BaridiMob Demo

**A learning project: an Arabic (RTL) mobile banking app UI built with Expo / React Native.**
All data is fake. It is not affiliated with Algérie Poste and does not connect to any real account.

# بريدي موب التجريبي

واجهة تطبيق مصرفي عربية (من اليمين لليسار) مبنية بـ **Expo / React Native**، مستوحاة من تطبيقات الدفع والخدمات المصرفية، بألوان **الأزرق الملكي `#0052CC` والذهبي `#FFB800`**.

> **تنبيه مهم:** هذا مشروع تعليمي وتجريبي. ليس تطبيق بريد الجزائر الرسمي، ولا علاقة له بالمؤسسة، ولا يتصل بأي حساب أو نظام حقيقي. كل الأرقام والأرصدة والفواتير والرموز وهمية، ولم تُستعمل فيه شعارات رسمية. لا تُدخل فيه بيانات بنكية حقيقية.

## المزايا

**الرئيسية**
- ترحيب باسم المستخدم، ورقم الحساب (RIP) مع زر نسخ
- الرصيد داخل صندوق متدرّج مع إخفاء وإظهار
- رمز QR الخاص بالحساب لمشاركة الـ RIP
- أزرار سريعة (تحويل، كشف الحساب، دفع، المزيد) وآخر العمليات

**التحويل والدفع**
- تحويل مع تحقق من الـ RIP (20 رقماً) والرصيد
- **قراءة رمز QR أو الباركود بالكاميرا** لتعبئة رقم الحساب تلقائياً
- **الدفع بالمسح** مع اسم التاجر والمبلغ (صيغة الرمز التجريبي أسفل الصفحة)
- **نماذج العمليات:** حفظ حسابات ومبالغ متكررة وإعادة استعمالها

**كشف الحساب**
- فلترة (الكل، المسحوبة، المستلمة) وبحث بالاسم وفترات زمنية
- تفاصيل كل عملية ومشاركة وصل نصي

**البطاقة الذهبية (Edahabia Classique)**
- بطاقة زرقاء بوجهين تُقلب بالضغط، بشريحة وزخارف زليج وظلال معالم جزائرية
- الوجه الخلفي بشريط مغناطيسي ومكان CVV
- إظهار وإخفاء الرقم وCVV، و**تجميد البطاقة** (يمنع الدفع بالمسح)

**قائمة المزيد**
- دفع الفواتير (سونلغاز، سيال، الجزائرية للمياه، اتصالات الجزائر)
- شحن الهاتف (موبيليس، جيزي، أوريدو) مع تحقق من بادئة الرقم
- سحب بدون بطاقة برمز مؤقت وعدّاد
- طلب دفتر شيكات وطلب أو تجديد البطاقة مع تتبّع الحالة
- الموزعات الآلية ومكاتب البريد (تفتح تطبيق الخرائط)
- معلومات مفيدة

**الإشعارات والملف الشخصي**
- إشعارات تتولّد مع كل عملية، مع عدّاد على الجرس
- ملف شخصي برقم الهاتف والـ RIP

**الأمان**
- رمز PIN من 4 أرقام يُحفظ في تخزين مشفّر (`expo-secure-store`)
- حدّ للمحاولات الخاطئة: كل 5 أخطاء تعطيل مؤقت متزايد
- قفل تلقائي عند مغادرة التطبيق (فوراً، 30 ثانية، دقيقة، 5 دقائق)
- فتح بالبصمة
- مراجعة كل عملية قبل تنفيذها، مع طلب الرمز أو البصمة
- إخفاء المحتوى ومنع لقطات الشاشة (اختياري)
- حفظ الرصيد والعمليات محلياً، وزر إعادة ضبط البيانات

## رحلة المشروع

1. **التصميم:** بدأ بتصميم الشاشة الرئيسية في Figma (إطار Android Medium، هيدر أزرق وبطاقة رصيد).
2. **بيئة العمل:** Linux Mint، و VS Code مع Prettier وESLint، و Node.js 22 عبر `nvm`، وGit.
3. **الانتقال إلى الكود:** بعد أن تعذّر تعديل التصميم بالكود داخل Figma على Linux، بُنيت الواجهة مباشرة في Expo وتُجرَّب على الهاتف عبر Expo Go.
4. **البناء المتدرّج:** الشاشة الرئيسية، ثم التدرجات الأزرق والذهبي، ثم التنقل والتحويل، ثم قراءة رموز QR، ثم الدفع بالمسح.
5. **التنظيم:** تقسيم الكود إلى مجلدات (ألوان، بيانات، أنماط، مكونات، شاشات).
6. **الحفظ والأمان:** حفظ البيانات محلياً، ثم رمز PIN، ثم القفل التلقائي والبصمة.
7. **البطاقة:** بطاقة ذهبية، ثم إعادة تصميمها زرقاء بوجهين بعد الاطلاع على التصميم المنشور للبطاقة الكلاسيكية الجديدة.
8. **الخدمات:** قائمة المزيد (فواتير، شحن، سحب، طلبات، نماذج)، ثم الإشعارات والملف الشخصي وتأكيد العمليات.
9. **الإخراج:** أيقونة بتصميم الفنك (رمز الجزائر) بألوان الأزرق والذهبي، وبناء ملف **APK** عبر EAS Build لتثبيته على الهاتف دون Expo Go.

## التشغيل

المتطلبات: Node.js 20 أو أحدث، وتطبيق **Expo Go** على هاتف أندرويد أو iOS.

```bash
# 1) أنشئ مشروع Expo فارغاً
npx create-expo-app@latest baridimob-app --template blank
cd baridimob-app

# 2) انسخ App.js ومجلد src من هذا المستودع إلى المشروع

# 3) ثبّت الحزم
npx expo install expo-linear-gradient expo-clipboard expo-camera react-native-svg \
  @react-native-async-storage/async-storage expo-secure-store \
  expo-local-authentication expo-screen-capture
npm install react-native-qrcode-svg

# 4) شغّل
npx expo start -c
```

امسح رمز QR الظاهر في الطرفية بتطبيق Expo Go. وإن لم يتصل الهاتف (مثلاً عند استعمال نقطة اتصال)، جرّب `npx expo start --tunnel`.

## بناء ملف APK

يحتاج حساباً مجانياً على [expo.dev](https://expo.dev):

```bash
npm install -g eas-cli
eas login
eas init
eas build:configure          # اختر Android
```

في `eas.json` اجعل ملف `preview` ينتج APK:

```json
"preview": {
  "distribution": "internal",
  "android": { "buildType": "apk" }
}
```

وفي `app.json` أضف معرّفاً فريداً داخل `android.package`، ثم:

```bash
eas build -p android --profile preview
```

عند انتهاء البناء يظهر رابط تحميل الملف. الأيقونة والاسم يظهران في هذه النسخة فقط، وليس داخل Expo Go.

## صيغة رمز الدفع التجريبي

لتجربة **الدفع بالمسح** أنشئ رمز QR بأي موقع توليد، وضع فيه:

```
BARIDI|رقم_RIP_من_20_رقماً|المبلغ|اسم_التاجر
```

مثال: `BARIDI|00799999000987654321|2500|مخبزة الأمل`

والمبلغ اختياري. وأي رمز يحوي 20 رقماً متصلة يُقبل في التحويل.
